Looks for ProPresenter's Network API on this machine only (make sure it's enabled in ProPresenter's Preferences > Network first). Or enter the host and port by hand below.

Searching the rest of the network is a bigger deal. It contacts every address on your local network looking for ProPresenter. Any ProPresenter it finds belongs to another machine that may be mid-service, and some networks treat a sweep like this as suspicious. Only do it if you know ProPresenter is running on a different computer.

Planning Center / shared-storage credentials for the optional arrangement-comparison module aren't collected here yet, because that module isn't built. When it lands, drop credentials into .env directly; see .env.example.
